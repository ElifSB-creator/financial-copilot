# 💼 Financial Copilot AI

An interactive, web-based financial intelligence application and credit risk portfolio prediction tool deployed on Hugging Face Spaces.

## 🚀 Overview
**Financial Copilot** is designed to streamline financial evaluation and risk assessment tasks. By combining automated data preprocessing, stress testing features, and an intuitive user interface, it bridges the gap between complex machine learning models and actionable financial insights.

## 🛠️ Tech Stack
* **Language:** Python
* **Web Framework / UI:** Streamlit
* **Machine Learning & Analytics:** Scikit-Learn, Pandas, NumPy
* **Deployment (Interface):** Hugging Face Spaces

## ✨ Key Capabilities
* **Interactive Risk Assessment:** Real-time scoring and default risk prediction through a clean web interface.
* **Robust Backend Logic:** Integrates optimized threshold tuning and imputation techniques to handle financial metrics securely.
* **Automated Stress Testing:** Evaluates portfolio resilience under various simulated economic conditions.
